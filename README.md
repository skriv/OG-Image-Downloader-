# OG Downloader

Chrome-расширение, которое читает Open Graph и соседние мета-теги текущей вкладки, показывает превью и скачивает картинку.

## Установка

1. Откройте Chrome → `chrome://extensions`
2. Включите **Режим разработчика**
3. Нажмите **Загрузить распакованное расширение**
4. Выберите папку `OGDownloader`

Иконка появится на панели. На любом сайте нажмите её, чтобы увидеть OG-картинку.

## Как пользоваться

- **Скачать** — файл сразу попадает в папку «Загрузки». Имя: `{сайт}-{заголовок}.{ext}`
- **Копировать URL** — сырая ссылка на картинку
- **Открыть** — картинка в новой вкладке
- Если картинок несколько, выберите миниатюру
- Правый клик по странице → **Скачать OG-картинку**
- Хоткей **Alt+Shift+O** открывает popup (на macOS тоже Option+Shift+O)

На `chrome://`, Web Store и PDF расширение не работает — это ограничение Chrome.

## Какие теги читаем

По приоритету:

1. `og:image`, `og:image:url`, `og:image:secure_url`
2. `twitter:image`, `twitter:image:src`
3. `<link rel="image_src">`
4. `itemprop="image"`, `vk:image`
5. JSON-LD `image` у `WebPage` / `Article` / `NewsArticle`

Также показываются title, description и размер, если он есть в мета-тегах или у самой картинки.

Локальная страница для проверки парсера: откройте `test/fixture.html` через любой HTTP-сервер (не `file://`).

## Разрешения

- **Чтение текущей вкладки** — чтобы взять мета-теги в момент клика
- **Загрузки** — сохранить файл
- **Доступ к сайтам** — скачать картинку с CDN, если прямой download блокируется

Историю, cookies и произвольные вкладки расширение не читает.
